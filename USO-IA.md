# Uso de IA

Registro de cada uso de inteligencia artificial generativa (ChatGPT, Claude, Copilot, etc.)
para generar o asistir un documento de este proyecto. Usar IA **no es una falta** — no
declarar un uso real, sí lo es.

Agreguen una entrada nueva (no editen ni borren las anteriores) cada vez que usen IA para un
documento, antes de pedir la revisión del Pull Request correspondiente.

## Cómo declarar un uso

```
## [Fecha] — [Nombre del estudiante]
- Herramienta: (ej. ChatGPT, Claude, Copilot)
- Documento/parte: (ruta del archivo) — permalink: (link a la línea/rango exacto)
- Qué se hizo con el resultado: (ej. "se usó como borrador y se reescribió", "se verificaron
  las cifras contra la norma X", "se usó tal cual")
```

## Ejemplo

```
## 2026-11-01 — Ana Pérez
- Herramienta: ChatGPT
- Documento/parte: 02_DHF_Proceso_Diseno/Fase_1_Investigacion/estado_del_arte.md — permalink:
  https://github.com/DisenoBiomedico-2/<repo>/blob/<sha>/02_DHF_Proceso_Diseno/Fase_1_Investigacion/estado_del_arte.md#L10-L25
- Qué se hizo con el resultado: se usó como borrador inicial y se reescribió comparando cada
  afirmación contra las fuentes citadas.
```
